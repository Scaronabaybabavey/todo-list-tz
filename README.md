# Список задач (To-Do List)

Простое веб-приложение для ведения списка задач на чистом HTML, CSS и JavaScript, без фреймворков и сборки.

**Демо:** https://scaronabaybabavey.github.io/todo-list-tz/

## Возможности

- Добавление новых задач (пустые задачи не добавляются)
- Отметка выполненных задач — по чекбоксу или клику на текст
- Удаление задач и кнопка «Удалить выполненные»
- Фильтры: все / активные / выполненные
- Счётчик оставшихся задач
- Сохранение в `localStorage` — задачи остаются после обновления страницы
- Синхронизация между открытыми вкладками
- Адаптивная вёрстка для телефона

## Запуск

Склонировать репозиторий и открыть `index.html` в браузере:

```bash
git clone https://github.com/Scaronabaybabavey/todo-list-tz.git
```

## Структура

```
index.html   — разметка
style.css    — стили
script.js    — логика и работа с localStorage
```
